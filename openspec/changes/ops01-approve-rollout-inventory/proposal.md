# Proposal

## Why

The repository does not identify an enterprise consumer, deployment topology, selected profile, trust boundaries, or accountable operating owners. A generic capability inventory cannot establish what controls apply to a particular bank deployment.

## What Changes

- Create an approved rollout record covering consumers, topology, profile, data/network boundaries, applicable control gates, and named service, security/control, and operations owners. Keep sensitive values in the approved operating system and link by stable reference.

## Capabilities

### New Capabilities

- `rollout-inventory-and-ownership`: approve rollout inventory and ownership evidence for an enterprise rollout.

### Modified Capabilities

None.

## Impact

Rollout evidence template and operator-owned inventory. The repository should contain only non-sensitive version/outcome/reference data.
