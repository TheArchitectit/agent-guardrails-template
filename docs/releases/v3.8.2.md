# Release Notes — v3.8.2

**Release Date:** November 6, 2026
**Type:** Patch (OpenSpec closure)

## What shipped

- **The four routed AIGGP packages are archived.** `aiggp-03` through `aiggp-06`
  (prompt-injection defense, semantic content filtering, runtime sandbox
  isolation, indirect-injection provenance) each stood at 5/5 tasks. Their spec
  deltas are now published as six specs — `categories-and-actions`,
  `evidence-and-conformance`, `isolation-levels`, `conformance-and-evidence`,
  `policy-and-conformance`, `provenance-records` — for 15 total, every one
  carrying a written Purpose and a `Status: CLOSED` line. Originals live under
  `openspec/changes/archive/2026-11-06-aiggp-0*/`.
- **`openspec/INDEX.md` no longer lists change packages.** The archive is the
  record now.
- **The publish pipeline can run again.** `guardrails-scan.mjs` — which the
  deploy script calls but no CI workflow does — reported 52 findings that
  predate this work. `pi-extension/` carries 50 TypeScript `any`/`console`
  findings. `mcp-server/` carries two false positives of overlay rules:
  PREVENT-003 reads the redaction marker `"<redacted>"` as a credential (the
  comment above it lost the words that suppress the rule), and PREVENT-009
  reads a deliberate `_ =` discard. Both trees are scoped out through
  `.guardrails/scope.json`, the project overlay, not by editing upstream rules.

## Validation

`openspec validate --all --strict` — 15 passed, 0 failed. `guardrails-scan.mjs`
— pattern scan clean. `regression_check.py --all --pre-commit` — pass.
`check_doc_length.py` — 479 files, all 10 over-cap files declared.

## Deliberate boundaries

This release changes no product code and no guardrail behavior. The two scoped
trees are untouched; their findings are recorded in the release note rather
than swept.
