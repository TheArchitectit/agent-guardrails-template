# Release Notes — v3.8.12

**Release Date:** November 27, 2026  
**Type:** Integration and CI hardening

## What shipped

- **The MCP service now rejects unauthorized access to optional Vision MCP
  and REST surfaces.** The changes cover the additional endpoints and retain
  the existing authorization checks on core routes.
- **IDE clients follow the shared REST contract.** Saved endpoint overrides
  are honored, selection requests use the canonical payload with legacy
  compatibility, and the VS Code client initializes against the supported
  endpoint.
- **The Team CLI install includes its Python backend.** Its JSON status and
  export modes now follow the documented output contract.
- **A process-local Kubernetes render profile is available for single-instance
  deployments.** The renderer preflights the actual Deployment, Service, and
  HPA, requiring one replica, a `Recreate` strategy, ClusterIP routing with no
  session affinity, and HPA bounds of 1..1. It emits YAML only; it does not
  contact a cluster or apply a deployment.
- **The Windows Docker Compose pilot has a repeatable setup path.** Its
  PowerShell flow configures the local stack and preserves user environment
  values during the versioned upgrade path.
- **MCP build contexts exclude local-only files.** `.dockerignore` keeps Git
  metadata, environment files, caches, and other local artifacts out while
  retaining the build inputs. The CI fixture checks the Docker CLI's filtered
  archive sent to a local receiver.

## Tooling and CI

- Pi's development test runner was updated to Vitest 5.1.2. The VS Code
  package now uses `@vscode/vsce` 4.1.2-4, includes the compiled entrypoint,
  and requires Node 22 or newer. Version 4.1.2-4 was a prerelease at
  verification time. The IntelliJ plugin is packaged for Java 17.
- MCP Go dependencies were updated for the source-reachable advisories
  identified in the prior audit, and a pinned `govulncheck` gate scans for
  future advisories.
- Python test suites and Go modules are enumerated from the repository and
  checked against the declared floors and module toolchains. CI workflows also
  contain a separate approved-AIGGP verification job and clean up its local
  checkout after the job.
- The Pi extension's `vitest` test suite passed 200 tests in 24 files; its
  recorded full and production-only npm audits each reported zero findings.
  VS Code install, compile, lint, tests, and local VSIX packaging passed in the
  integrated QA-04 evidence. The VS Code package tool is a prerelease, and the
  VSIX was not uploaded or published.

## Verification scope

- The process-local renderer and CLI were verified on AI03. Independent
  serialized-file validation passed; malformed YAML, missing Service ports,
  and incompatible replica settings were rejected. The eight renderer fixtures
  and the missing-ports CLI regression passed. Strict OpenSpec 2.2.0 validation
  reported 73 passed items. No cluster deployment was performed.
- IntelliJ Plugin Verifier 1.411 reported compatibility for IDEA Community
  builds IC-223.8836.41 and IC-241.19416.15. Both reports include one
  scheduled-for-removal API use and two deprecated API uses; this is not
  verification of other IntelliJ products or builds.
- The Docker context transport fixture passed on the three Guardrails runner
  containers. It verified the client's filtered archive, not image building
  or execution of the Dockerfile.
- Python coverage reports are uploaded as GitHub Actions artifacts with a
  seven-day retention period.
