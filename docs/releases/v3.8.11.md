# Release Notes — v3.8.11

**Release Date:** November 13, 2026
**Type:** CI correctness (scan scope)

## What shipped

- **`scripts/check-doc-links.sh` skips `.devgate/`.** The pinned submodule is a
  separate repository with its own documentation gate. On the persistent UCS03
  workspace it survives into jobs that do not check out submodules, so the
  template's link gate was reading 730 files instead of 513 and failed on a
  link inside the submodule.
- **The secret pattern scan skips `.devgate/`** (`--exclude-dir=.devgate`). The
  submodule's own test canary and `TOKEN="$VAR"` idioms are not template
  findings, and the submodule has its own secret gates.

Both changes make the gate deterministic: its result no longer depends on
whether an earlier job on the same runner populated the submodule. No product
code changed.
