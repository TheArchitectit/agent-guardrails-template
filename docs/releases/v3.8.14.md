# Release Notes — v3.8.14

**Release Date:** November 27, 2026  
**Type:** Local CI validation

## Changes

- Local validation runs the documentation length and link checks, Go advisory
  scan, team CLI fixture checks, and Docker client context-transport test along
  with the Python and Go inventories and deterministic policy gates.
- The local event command runs secret and lint checks for an explicit push or
  pull request commit range. It uses the pinned Gitleaks scanner and the same
  repository allowlists as the workflows.
- The Docker/Podman live-engine integration test remains opt-in. Local
  validation does not publish artifacts, send PR comments, perform release
  publication, or attest a remote runner.

See [local validation](../ci/local-validation.md) and
[local event gates](../ci/local-event-gates.md) for prerequisites and usage.
