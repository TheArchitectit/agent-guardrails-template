## Note on historical accuracy

Release notes are a historical record and are **not** rewritten when later
code changes invalidate them. Counts such as "35 tools" in v3.3.0 and
v3.4.0 describe the server as it stood at that release. For the current
tool surface see
[../mcp-server/tools-reference.md](../mcp-server/tools-reference.md).
