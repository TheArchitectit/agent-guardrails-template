# v3.8.15

The UCS03 lab CI jobs request a disposable offline KVM guest on AI05 to build
the production MCP image from the exact Git commit, apply migrations and run
a deterministic MCP probe. The signed receipt ties its image digest and
protocol results to the requesting job. Unattended builds use no model tokens.
Operators can run the real Codex client test on demand.

The portable suite uses the same local CI entry point on local machines,
GitHub-hosted Ubuntu and the configured self-hosted fleet. The OpenSpec index
connects the specifications, change proposals, sprint assignments and evidence.

See the [worker guide](../ci/guardrails-per-build-worker.md),
[qualification receipts](../../openspec/changes/qualify-ci-environment-and-mcp-client/evidence.md)
and [OpenSpec index](../../openspec/INDEX.md).
