# Prompting Guide

> How to write prompts that work with Agent Guardrails

**TL;DR:** Be explicit, provide context, define scope, and the guardrails will keep your AI on track.

## Topics

- [Fundamentals](prompting-fundamentals.md) — The golden rules, quick reference card, and a practice exercise
- [Templates](prompting-templates.md) — Ready-to-use prompt templates for features, bug fixes, reviews, refactoring, and docs
- [Patterns](prompting-patterns.md) — Common prompt patterns: scoped requests, step-by-step, reference, validation gates, context-rich
- [Advanced Techniques](prompting-advanced-techniques.md) — Progressive disclosure, constraint programming, example-driven, hypothetical reasoning, role play
- [Use Cases](prompting-use-cases.md) — Worked examples for API development, frontend components, database migrations, and DevOps
- [Anti-Patterns and Troubleshooting](prompting-anti-patterns.md) — What to avoid and how to fix common prompting problems
- [Vibe Coding](prompting-vibe-coding.md) — Rapid development patterns for high-velocity AI sessions

---

Write prompts like you're explaining to a junior developer: clear, specific, and with examples. The guardrails catch mistakes, but a good prompt prevents them from being needed.
