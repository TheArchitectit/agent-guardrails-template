# Archive

Point-in-time documents from past sprints, reviews, and planning rounds. Kept
for historical reference — not maintained, not wired into the live navigation.
Facts here (tool counts, versions, architecture) reflect the state when they
were written and are almost certainly out of date.

| Directory | Contents |
|-----------|----------|
| `plans/` | Implementation plans (MCP server plan, Project Sentinel, gap remediation branch) |
| `reviews/` | Audit and platform-review reports (April audit, June 2026 review + implementation report) |
| `gap-analyses/` | Team-tools gap analysis and remediation plan |
| `sprints/` | All sprint records — MCP gap sprints (001–006), the sprint guide/template, and enterprise readiness sprints (v1.0–v1.4) |
| `architecture/` | Superseded architecture docs (Clean CQRS map — referenced a code package that was never finished) |
