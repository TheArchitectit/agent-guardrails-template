## 0. Method and status vocabulary

Each requirement/scenario is classified against the code **as it exists at HEAD**, by
reading source and running the cited tests (`mcp-server`, `go1.25.5`, focused
`go test` executed in this audit). Strict vocabulary, ascending strength:

| Status | Meaning |
|---|---|
| **ABSENT** | No implementation in the repo (or the spec is explicitly a proposal with no shipped artifact). |
| **WIRED** | Implementation exists but **no exact live/path test** proves it end-to-end. Includes "code complete, not reachable from the request path." |
| **EXERCISED** | An exact test for this requirement **ran and passed** in this audit (test name cited). |
| **ACCEPTED** | Implementation + exercised test + end-to-end/request-path evidence with no open caveat. |
| **NOT_RUN** | The harness/runner/live dependency required to judge was not available (e.g. CI required-check settings, container runtime, real PostgreSQL). Never implies passing. |

`NOT_RUN` is **not** a pass and is never collapsed into `EXERCISED`/`ACCEPTED`.
Nothing in this audit is `ACCEPTED`; no requirement carries full request-path proof
plus a green external gate simultaneously.

Two facts drive most of the picture:

1. **The library-vs-shipped gap (gaps 01/03/04/05/06).** Large, tested Go libraries
   (injection pipeline, sandbox, multi-agent chains, provenance, compliance) are
   constructed at startup and reached only from `*_test.go`. `Engine.Evaluate` — the
   only caller of the injection/provenance pipeline — has **zero non-test callers**:
   ```
   mcp-server/internal/guardrails/{bash,git,fileedit}/slice.go  → registry dispatch
   mcp-server/internal/guardrails/engine_test.go:34,78          → test only
   ```
   The two shipped content tools call `ClassifyContent`/`CheckPolicy` and **bypass
   provenance entirely** (`tools_guardrails.go:77,107,112`).
2. **Phase 0 remediation (specs 11/12/16/17/18/19).** Commit range
   `9d8defe`…`994e4cf` landed real auth/registry/exposure/migration work with tests,
   reconciled in `docs/sprints/SPRINT-A0…A4`. Much of 11/16 is now WIRED/EXERCISED;
   12/13/17/18/19 are partial, with release-gating external evidence still NOT_RUN.
