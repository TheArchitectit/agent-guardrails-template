## Follow-up (new item, spun into spec 26)

The OMCP server used for this run self-terminates its HTTP listener after
`shutdown::GRACE` (10 s) even without an inbound signal, because
`shutdown::serve_until_within` wraps the whole `axum::serve(...)` future in
`tokio::time::timeout(GRACE, ...)` (`crates/server/src/shutdown.rs`). That caps
each server instance at ~10 s and is why every Inspector step was run against a
freshly started instance. It does not affect any step's verdict, but it is a
real defect in the serve loop; recorded as **spec 26**.
