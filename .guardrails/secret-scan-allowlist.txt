# Secret-scan synthetic-fixture allowlist
#
# Narrow, exact-path allowlist for KNOWN synthetic fixtures matched by the
# blocking checks in .github/workflows/secret-validation.yml:
#
#   - "Check for credential files" (job check-env-files): entries are exact
#     repo-relative paths; an allowlisted file does not fail the step.
#   - "Check for common secret patterns" (job check-hardcoded-secrets): the
#     entry's file name is excluded from the source grep.
#
# Rules (Spec 19 R19-06):
#   - One repo-relative path per line. No globs, no directories.
#   - The file MUST contain only unmistakably synthetic credentials
#     (placeholder / redacted / obviously fake values). Never add a real secret.
#   - Every entry MUST carry a justification comment on the line above.
#   - Do not use this allowlist to suppress full-history Gitleaks findings;
#     that scanner has its own configuration.
