# Growth kit (repo-agnostic star package)

Reusable for every public repo. Earned tactics only: no bought stars, no star exchanges, no sock accounts, no "star for a gift".
Copy `STAR-PLAN.template.md` into a repo's planning folder, replace the `{{...}}` fields, then run `./repo-readiness.sh <repo-dir>`.
Thresholds are direction, not promises; no dates.
